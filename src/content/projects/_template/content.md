# Your Project Walkthrough

This is a template project. 

### Instructions to create a new project:
1. Duplicate this `_template` folder and rename it to your project's slug (e.g., `my-new-project`). Since the folder name no longer starts with `_`, the site will automatically detect and build it!
2. Update the `metadata.json` with your project's details, including category and asset links.
3. Replace this `content.md` with your deep-dive walkthrough.
4. Drop any files (like STLs, APKs, or ZIPs) in the Next.js `public/` directory (for example, `public/apks/`) and map them in the `assets` array in your `metadata.json`.
