# Smart Mirror

Building this smart mirror was one of my favorite projects. It combines software with a 3D printed back casing that holds the Raspberry Pi and the display controller exactly where they need to go.

### Software Stack
- Node.js
- React (for the smart mirror interface)
- Python (for hardware interactions with sensors)

### The Hardware
I designed the 3D model in Fusion 360 to securely snap onto the back of the LCD panel. The STL file is available for viewing.
