# When to follow AGENTS.md

If a request involves any of the following, treat it as a **new project task** and follow `AGENTS.md` in full before writing any code or files:

- Adding a new project to the site
- Filling in project details from a template or user-provided notes
- Creating or editing anything under `src/content/projects/` or `public/projects/`
- Moving or renaming a project folder
- Assigning a project to a series (subcategory)

In these cases: read `AGENTS.md`, then read `src/content/projects/_template/FORMATTING_GUIDE.md`, then act.
